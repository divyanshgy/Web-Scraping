# Web-Scraping
 Web scraping using python for financial data
 1) Basics folder contains two python programs, one for scraping data from a local html file and another for scraping data from live website.
 2) Finance folder has files:
    nifty50.py - python program for scraping ET website for financial news for Nifty 50 stocks dated 1 Jan 2020. These are further stored in a CSV file which
    has columns Date, News, Ticker and this Dataframe can be further used for NLP and sentiment analysis.
